## 🌐 Déploiement Netlify

### Option 1: Drag-drop (PLUS FACILE) ⭐
1. Allez sur: https://app.netlify.com/
2. Connectez-vous
3. **Drag-drop ce dossier** sur la page
4. ✅ Site live en 10 secondes!

### Option 2: GitHub
1. Push ce dossier sur GitHub
2. Netlify → "New site from Git"
3. Sélectionnez le repo
4. Auto-déploiement! ✅
